# docs/ - 技術ドキュメント

このディレクトリには、Shaberi評価フレームワークの構造化出力移行に関する技術ドキュメントが含まれています。

## 命名規則

### ファイル命名形式
```
YYYYMMDD-{category}-{description}.md
```

- **YYYYMMDD**: 作成日（例：20250620）
- **category**: カテゴリ名（evaluations, schema, git, etc.）
- **description**: 内容の簡潔な説明

### カテゴリ分類
- **evaluations**: 評価結果の分析・比較
- **schema**: システム設計・実装手順  
- **git**: Git操作・履歴管理
- **dev**: 開発プロセス・ツール
- **ops**: 運用・保守

## 目的

これらのドキュメントは以下の目的で作成されています：

1. **技術仕様の記録**: 構造化出力移行の設計思想と実装方針
2. **評価結果の分析**: 従来システムとの比較検証データ
3. **開発プロセスの文書化**: 実装過程で得られた知見とベストプラクティス
4. **運用ノウハウの蓄積**: Git操作やトラブルシューティングの手順
5. **将来の拡張指針**: 他ベンチマークへの適用や改良の方向性
