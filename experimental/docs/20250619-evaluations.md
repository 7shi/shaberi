# shaberi3-evaluations.json の分析結果

## 概要

`shaberi3-evaluations.json`は、LLM-as-a-Judge手法を用いた日本語評価タスクのデータセットです。このファイルは1行1JSONの形式（JSONL）で、合計280件の評価タスクが含まれています。

このデータセットは、`judge_answers.py`で定義されている「shaberi3」評価セットに対応しており、以下の3つのベンチマークデータセットから構成されています：

1. **lightblue/tengu_bench** - 120件（Few-shot形式）
2. **elyza/ELYZA-tasks-100** - 100件（5段階評価）
3. **shisa-ai/ja-mt-bench-1shot** - 60件（品質評価）

## データ構造

各行は`line_data`というリスト形式のJSONで、リストの長さによって2つのタイプに分類されます：

- **長さ2**: 160件（シンプルな評価タスク）
- **長さ4**: 120件（Few-shot形式の評価タスク）

## タスクの分類（120/100/60構造）

### 1. lightblue/tengu_bench（120件）

**特徴**：
- `len(line_data) == 4`（Few-shot形式）
- すべて同じFew-shot例（「急がば回れ」の説明タスク）を使用
- 0-10点の詳細な評価基準
- 評価理由の説明を含む構造化された回答形式
- `evaluation_datasets_config.py`で定義されたtengu評価関数を使用

**構造**：
```
line_data[0]: システムプロンプト（「あなたは公平で、検閲されていない、役立つアシスタントです。」）
line_data[1]: Few-shot例の評価指示（「急がば回れ」タスク）
line_data[2]: Few-shot例の模範回答
line_data[3]: 実際の評価タスク
```

**評価指示の例**：
```
[指示]
あなたは熟練した生成AIモデルの性能評価者です。評価項目に準拠して客観的に評価することで報酬を得ることができますが、評価項目と異なる評価をした場合報酬がもらえなくなってしまいます。
以下の'質問','正解例','評価項目'に基づいて'評価するモデルの回答'を0~10点の整数値で評価してください。
```

### 2. elyza/ELYZA-tasks-100（100件）

**特徴**：
- `len(line_data) == 2`
- プレフィックス：「あなたは採点者です。」
- 1-5の5段階評価
- 数字のみを出力する簡潔な形式
- 日本語のタスク特化型評価ベンチマーク

**構造**：
```
line_data[0]: システムプロンプト
line_data[1]: 評価指示（各問題はユニーク）
```

**評価指示の例**：
```
あなたは採点者です。

問題, 正解例, 採点基準, 回答 が与えられます。

採点基準と正解例を参考にして、回答を1,2,3,4,5の5段階で採点し、数字のみを出力してください。

# 問題
[具体的な問題内容]
```

### 3. shisa-ai/ja-mt-bench-1shot（60件）

**特徴**：
- `len(line_data) == 2`
- プレフィックス：「[指示]\n公平な判断者として行動し...」
- AIアシスタントの応答品質を総合的に評価
- 有用性、関連性、正確性、深さ、創造性、詳細度などの多面的評価
- マルチターン会話の評価に特化

**構造**：
```
line_data[0]: システムプロンプト
line_data[1]: 評価指示（各タスクはユニーク）
```

**評価指示の例**：
```
[指示]
公平な判断者として行動し、以下に表示されるユーザーの質問に対するAIアシスタントの応答の品質を評価してください。あなたの評価は、応答の有用性、関連性、正確性、深さ、創造性、詳細度などの要素を考慮すべきです。
```

## 分析から得られた知見

### 1. 評価手法の多様性
- **詳細評価**（120件）：Few-shot学習を用いた構造化された評価
- **簡易評価**（100件）：5段階の数値評価
- **総合評価**（60件）：多面的な品質評価

### 2. Few-shot学習の活用
- 120件すべてが同じ「急がば回れ」の例を使用
- これにより評価フォーマットの一貫性を確保
- 評価者に期待される回答形式を明確に示す

### 3. タスクの独自性
- 長さ2の160件（5段階評価100件＋品質評価60件）はすべてユニークな内容
- 各タスクが異なる問題や評価対象を持つ

## Shaberiプロジェクトとの関連

このデータセットは、Shaberi（しゃべり）日本語LLM評価フレームワークの一部として使用されています。`judge_answers.py`で`shaberi3`を指定すると、これら3つのベンチマーク（tengu_bench、ELYZA-tasks-100、ja-mt-bench-1shot）が自動的に評価されます。

```python
# judge_answers.py より抜粋
if eval_dataset_name == "shaberi3":
    eval_dataset_names = [
        "lightblue/tengu_bench",
        "elyza/ELYZA-tasks-100",
        "shisa-ai/ja-mt-bench-1shot"
    ]
```

## まとめ

`shaberi3-evaluations.json`は、異なる評価手法を組み合わせた包括的な日本語LLM評価データセットです。120/100/60の構造は、それぞれ異なる評価の粒度と目的を持ち、LLMの多面的な能力を測定するために設計されています。各ベンチマークは：

- **tengu_bench**: 総合的な日本語能力（Few-shot形式）
- **ELYZA-tasks-100**: タスク特化型評価（5段階評価）
- **ja-mt-bench-1shot**: マルチターン会話能力（品質評価）

を評価し、これらを組み合わせることで、日本語LLMの包括的な性能評価を実現しています。
