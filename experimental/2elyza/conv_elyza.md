# conv_elyza.py - ELYZA-tasks-100データ分割ツール

## 概要

`conv_elyza.py`は、ELYZA-tasks-100ベンチマークの元データ（`2elyza.json`）を個別ファイルに分割するツールです。元のJSONデータを加工せずに、各タスクの評価プロンプト文字列を個別の`.md`ファイルに出力します。

## 機能

1. **データの単純分割**: `2elyza.json`から100個のタスクを読み込み
2. **個別ファイル出力**: 各タスクを`data/001.md`～`data/100.md`に分割
3. **データ保持**: 元のJSONデータ構造を一切変更せずに保持

## 使用方法

```bash
# 2elyzaディレクトリ内で実行
cd 2elyza
uv run conv_elyza.py
```

## 入力

- `../2elyza.json`: ELYZA-tasks-100の評価タスク（JSONL形式）

## 出力

- `data/001.md` ～ `data/100.md`: 各タスクの評価プロンプト文字列

## 出力例

### 生成されるファイル例（data/001.md）
```
あなたは採点者です。

問題, 正解例, 採点基準, 回答 が与えられます。

採点基準と正解例を参考にして、回答を1,2,3,4,5の5段階で採点し、数字のみを出力してください。

# 問題
仕事の熱意を取り戻すためのアイデアを5つ挙げてください。

# 正解例
1. 自分の仕事に対する興味を再発見するために、新しい技能や知識を学ぶこと。
...

# 採点基準
基本的な採点基準
- 1点: 誤っている、 指示に従えていない
...

# 回答
未回答
```

## 技術的詳細

### データ処理フロー
1. `../2elyza.json`をJSONL形式で読み込み
2. 各行を`json.loads()`でパース
3. パースした文字列内容をそのまま`.md`ファイルに出力

### 設計上の決定
1. **シンプルな構成**: データ変換なしの単純分割
2. **元データ保持**: 一切の加工を行わない
3. **拡張性**: 後続の処理ツールで活用可能

## エラー処理

- 入力ファイルが存在しない場合はエラーメッセージを表示
- 各タスクの処理は独立しており、1つの失敗が全体に影響しない
- 出力ディレクトリは自動的に作成される

## 活用例

分割されたファイルは以下のような用途で活用できます：

1. **個別タスクの検証**: 特定のタスク内容を詳細確認
2. **データ分析**: タスクごとの構造や内容の解析
3. **カスタム評価**: 特定タスクのみを対象とした評価実行
