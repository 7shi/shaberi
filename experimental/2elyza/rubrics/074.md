def judge_074(score: int, judge: callable) -> int:
    # 評価基準:
    # - 生徒の要約をベースに大きな変更を加えずに改善し、改善点を説明する: 4点
    # - 生徒の要約をベースに大きな変更を加えずに改善する: 4点
    # - 生徒の要約をベースにせずに、単純にゼロから記事を要約している: 3点
    # - 生徒の要約をベースにせずに、単純にゼロから記事を要約しているが、その要約の品質が低い: 2点

    # これらの評価基準は排他的な状態を表し、それぞれ特定のスコアを割り当てている。
    # そのため、最も限定的で低いスコアに結びつく条件から順に判定し、
    # 該当した場合はそのスコアを設定する `if-elif` 構造が適切である。

    # 1. 最も低いスコアの条件から判定 (2点)
    # 「生徒の要約をベースにせずに、単純にゼロから記事を要約しているが、その要約の品質が低い」
    if judge("生徒の要約をベースにせずに、単純にゼロから記事を要約しており、その要約の品質が低い"):
        score = 2
    # 2. 次に低いスコアの条件 (3点)
    # これは「生徒の要約をベースにせずに、単純にゼロから記事を要約している」が、
    # 上記の「品質が低い」ケースではない場合（つまり、品質はそこそこ良い場合）。
    elif judge("生徒の要約をベースにせずに、単純にゼロから記事を要約している"):
        score = 3
    # 3. 高いスコアの条件 (4点)
    # これは「生徒の要約をベースに大きな変更を加えずに改善している」場合。
    # 評価基準には「改善点を説明する」と「改善する」の2つがあるが、どちらも4点なので、
    # より一般的な条件である「改善する」でまとめて判定する。
    elif judge("生徒の要約をベースに大きな変更を加えずに改善している"):
        score = 4
    # 上記のどの条件にも当てはまらない場合、scoreは初期値（通常5点）のまま返される。
    # これは、例えば「生徒の要約をベースにしたが、改善はしていない」などのケースに該当し、
    # 評価基準に明記されていないため、減点対象ではないと解釈される。

    return score
