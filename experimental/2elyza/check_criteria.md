# check_criteria.py - ELYZA-tasks-100 問題固有採点基準抽出ツール

## 概要

`check_criteria.py`は、ELYZA-tasks-100の各タスクファイル（`data/*.md`）から「問題固有の採点基準」を抽出・表示するツールです。各タスク特有の評価基準を一覧で確認でき、評価システムの設計や品質管理に活用できます。

## 機能

1. **一括抽出**: `data/`ディレクトリ内の全`.md`ファイルを自動検索
2. **範囲指定抽出**: 「問題固有の採点基準」～「# 回答」の間の内容のみを取得
3. **自動整形**: 空行を除去し、strip()でクリーンアップ
4. **番号順表示**: ファイル名でソートされた順序で結果を表示

## 使用方法

### 基本実行

```bash
# 2elyzaディレクトリ内で実行
cd 2elyza
uv run check_criteria.py
```

### 実行例

```
# 001

- 熱意を取り戻すのではなく、仕事の効率化・スキルアップのような文脈になっていたら1点減点
- 出したアイデアが5つより多い、少ない場合は1点減点
- 5つのアイデアのうち、内容が重複しているものがあれば1点減点

# 002

- クマが海辺に行く
- クマとアザラシが友達になる
- 最後に家に帰る
の3つ要素が必要で、欠けている場合: 5点ではなく3点になる
短編小説として淡白な場合: -1点
```

## 入力

- **対象ファイル**: `data/001.md` ～ `data/100.md`（ELYZA-tasks-100の分割タスクファイル）
- **抽出範囲**: 各ファイル内の「問題固有の採点基準」セクション

## 出力

- **形式**: コンソール出力（標準出力）
- **構成**: 
  - タスク番号（# 形式）
  - 抽出された採点基準行
- **結果**: [rubrics.md](rubrics.md)に保存された全タスクの採点基準

## 技術的詳細

### データ処理フロー

1. **ファイル検索**: `glob.glob("data/*.md")`でファイル一覧取得
2. **順次処理**: 各ファイルを`sorted()`で番号順に処理
3. **範囲抽出**: 開始マーカー検出後、終了マーカーまでの行を収集
4. **整形出力**: 空行除去とstrip()処理後に表示

## 出力パターン分析

### 基準の分類例

**定量的基準**:
- アイデア数（5つ）
- 計算結果の正誤
- 要素の過不足

**定性的基準**:
- 文体の適切性
- シチュエーションとの合致
- 創造性・独創性

**減点項目**:
- 指示不従順（-4点）
- 文脈のズレ（-2点）
- 表現の不自然さ（-1点）
