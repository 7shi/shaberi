# conv_tengu.py - Tengu Benchmark 変換スクリプト

## 概要

`conv_tengu.py`は、Shaberi評価フレームワークの`../1tengu.json`ファイルから、個別のMarkdownファイルに変換するスクリプトです。構造化出力（JSONスキーマ）による評価システムへの移行を支援するため、各評価タスクを独立したファイルとして管理できるようにします。

## 背景

### 従来の問題点

1. **統合ファイルの管理困難**: 120件の評価タスクが1つのJSONファイルにまとめられている
2. **個別編集の不便さ**: 特定のタスクを修正する際に大きなファイル全体を扱う必要がある
3. **スキーマ変換の準備不足**: Few-shot形式から構造化出力への移行時に個別処理が困難

### 解決アプローチ

各評価タスクを独立したMarkdownファイルに分割することで：

- **個別管理**: 各タスクを独立して編集・管理可能
- **スキーマ変換準備**: 後続の自動変換処理に適した形式
- **バージョン管理**: Gitでの差分管理が容易

## 入力データ

### ソースファイル: ../1tengu.json

- **形式**: JSONL（JSON Lines）
- **件数**: 120件のtengu_bench評価タスク
- **構造**: 1行1JSONで評価指示文が文字列として格納

```json
"[指示]\nあなたは熟練した生成AIモデルの性能評価者です。..."
```

### データの由来

`../1tengu.json`は`dump_questions.py`により`shaberi3-evaluations.json`から抽出されたtengu_bench専用データです。元データは以下の構造を持つFew-shot形式の評価タスクです：

```json
[
  {"role": "system", "content": "システムプロンプト"},
  {"role": "user", "content": "Few-shot例の評価指示"},
  {"role": "assistant", "content": "Few-shot例の模範回答"},
  {"role": "user", "content": "実際の評価タスク"}  ← これを抽出
]
```

## 処理フロー

### 1. ファイル読み込み
- `../1tengu.json`の存在確認
- UTF-8エンコーディングでの読み込み

### 2. 出力準備
- `data/`ディレクトリの作成（存在しない場合）

### 3. 変換処理
```python
for i, line in enumerate(lines, 1):
    md_content = json.loads(line.strip())
    output_file = output_dir / f"{i:03d}.md"
    with open(output_file, 'w', encoding='utf-8') as f:
        f.write(md_content)
```

### 4. エラーハンドリング
- JSONパースエラーの適切な処理
- 処理結果の統計出力

## 出力ファイル

### ディレクトリ構造
```
data/
├── 001.md
├── 002.md
├── ...
└── 120.md
```

### ファイル命名規則
- **形式**: `{番号:03d}.md`
- **番号範囲**: 001-120
- **例**: `001.md`, `042.md`, `120.md`

### ファイル内容
各ファイルには元の評価タスクの内容がそのまま保存されます：

```markdown
[指示]
あなたは熟練した生成AIモデルの性能評価者です。評価項目に準拠して客観的に評価することで報酬を得ることができますが、評価項目と異なる評価をした場合報酬がもらえなくなってしまいます。
以下の'質問','正解例','評価項目'に基づいて'評価するモデルの回答'を0~10点の整数値で評価してください。

[質問]
...

[正解例]
...

[評価項目]
...
```

## 使用方法

### 実行コマンド
```bash
cd experimental
uv run conv_tengu.py
```

### 前提条件
- `1tengu.json`が親ディレクトリに存在すること
- Python 3.6以上
- 必要な権限（ディレクトリ作成・ファイル書き込み）

### 実行結果例
```
処理中: 120件の評価タスク

変換完了:
  成功: 120件
  エラー: 0件
  出力ディレクトリ: data
```

## 技術仕様

### 依存関係
- **標準ライブラリのみ**: `json`, `pathlib`
- **外部依存なし**: 追加インストール不要

### 文字エンコーディング
- **入力**: UTF-8
- **出力**: UTF-8
- **日本語対応**: 完全サポート

### エラー処理
- JSONパースエラーの個別捕捉
- 処理継続（1件のエラーで全体が停止しない）
- 詳細なエラーレポート

## 次のステップ

このスクリプトで生成されたMarkdownファイルは、以下の用途に活用できます：

1. **スキーマ変換**: MDからJSONスキーマへの自動変換
2. **個別編集**: 特定のタスクの評価基準調整
3. **品質管理**: 各タスクの内容検証と改善
4. **カスタム評価セット**: 特定のタスクのみを使用した評価の実行
