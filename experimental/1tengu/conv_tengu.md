# conv_tengu.py - Tengu Benchmark 変換スクリプト

## 概要

`conv_tengu.py`は、Shaberi評価フレームワークの`../1tengu.json`ファイルから、個別のMarkdownファイルに変換するスクリプトです。構造化出力（JSONスキーマ）による評価システムへの移行を支援するため、各評価タスクを独立したファイルとして管理できるようにします。

## 背景

**Problem**: 120件の評価タスクが1つのJSONファイルに統合され、個別編集やスキーマ変換が困難。

**Solution**: 各タスクを独立したMarkdownファイルに分割し、個別管理とスキーマ変換の準備を実現。

## 入力データ

### ソースファイル: ../1tengu.json

- **形式**: JSONL（JSON Lines）
- **件数**: 120件のtengu_bench評価タスク
- **構造**: 1行1JSONで評価指示文が文字列として格納

```json
"[指示]\nあなたは熟練した生成AIモデルの性能評価者です。..."
```

### データの由来

`../1tengu.json`は`dump_questions.py`により`shaberi3-evaluations.json`から抽出されたtengu_bench専用データです。元データは以下の構造を持つFew-shot形式の評価タスクです：

```json
[
  {"role": "system", "content": "システムプロンプト"},
  {"role": "user", "content": "Few-shot例の評価指示"},
  {"role": "assistant", "content": "Few-shot例の模範回答"},
  {"role": "user", "content": "実際の評価タスク"}  ← これを抽出
]
```

## 処理フロー

1. **入力**: `../1tengu.json`読み込み
2. **出力準備**: `data/`ディレクトリ作成
3. **変換**: JSONLの各行を`{i:03d}.md`ファイルに出力
4. **エラーハンドリング**: JSONパースエラーと結果統計

## 出力ファイル

- **ディレクトリ**: `data/`
- **ファイル形式**: `001.md` - `120.md`（連番3桁）
- **内容**: 元の評価タスクをそのまま保存

## 使用方法

### 実行コマンド
```bash
cd experimental
uv run conv_tengu.py
```

### 前提条件
- `1tengu.json`が親ディレクトリに存在すること
- Python 3.6以上
- 必要な権限（ディレクトリ作成・ファイル書き込み）

### 実行結果例
```
処理中: 120件の評価タスク

変換完了:
  成功: 120件
  エラー: 0件
  出力ディレクトリ: data
```

## 技術仕様

- **依存**: 標準ライブラリのみ（`json`, `pathlib`）
- **エンコーディング**: UTF-8、日本語完全対応
- **エラー処理**: JSONパースエラー個別捕捉、処理継続

## 次のステップ

このスクリプトで生成されたMarkdownファイルは、以下の用途に活用できます：

1. **スキーマ変換**: MDからJSONスキーマへの自動変換
2. **個別編集**: 特定のタスクの評価基準調整
3. **品質管理**: 各タスクの内容検証と改善
4. **カスタム評価セット**: 特定のタスクのみを使用した評価の実行
