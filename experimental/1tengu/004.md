[正解例]
この問題では数学と英語の少なくとも一方の点数が15点以下の生徒の人数の最小値と最大値を求める必要があります。
今、表では0-9点、10-19点、20-29点、30-39点、40-50点の間の人数しか与えられていないため、15点以下の人数を正確に知ることができないですが最小値と最大値は求めることができます。
15点以下の点数である可能性がある範囲は0-9点と10-19点であり、0-9点の時は必ず15点以下である一方で10-19点の場合は15点以下ではない可能性があります。そのため、数学と英語の少なくとも一方が0-9点の範囲にいる人数が最小値となり、数学と英語の少なくとも一方が0-9点もしくは10-19点の範囲にいる人数が最大値となります。

1. 数学と英語の少なくとも一方が0-9点の範囲にいる人数
(数学が0-9点の範囲にいる人数) = 0+1+0+0+0 = 1人
(英語が0-9点の範囲にいる人数) = 0+0+2+0+0 = 2人
(数学と英語のいずれも0-9点の範囲にいる人数) = 0人
(数学と英語のいずれかが0-9点の範囲にいる人数) = 1+2-0 = 3人
よって最小値は3人である。

2. 数学と英語の少なくとも一方が0-9点もしくは10-19点の範囲にいる人数
(数学が0-9点の範囲にいる人数) = 0+1+0+0+0 = 1人
(数学が10-19点の範囲にいる人数) = 0+1+2+3+0 = 6人
(英語が0-9点の範囲にいる人数) = 0+0+2+0+0 = 2人
(英語が10-19点の範囲にいる人数) = 1+1+1+2+0 = 5人
(数学と英語のいずれも0-9点もしくは10-19点の範囲にいる人数) = 0+1+0+1 = 2人
(数学と英語のいずれかが0-9点もしくは10-19点の範囲にいる人数) = 1+6+2+5-2 = 12人
よって最大値は12人である。

よって数学と英語の少なくとも一方の得点が15点以下の生徒は、3人から12人の間である。
